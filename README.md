## About Me

I'm a **backend engineer** focused on building **large-scale, high-performance systems**. I currently work on backend infrastructure that handles **100M+ (10 crore+) records**, where performance, reliability, and clean architecture really matter.

My work covers **system architecture**, **API design**, **database optimization**, and **containerized deployments with Docker**. I enjoy figuring out how to make systems faster, more reliable, and easier to scale, whether that means designing a better schema, tuning slow queries, adding caching, or restructuring services.

Always open to discussing distributed systems, scaling challenges, and interesting backend problems.

<br>

## What I Work On

- ⚙️ Designing and building **scalable backend services and REST APIs**
- 🗄️ Managing and optimizing databases at **100M+ record scale**
- 🐳 Containerizing and deploying services with **Docker**
- 🏗️ Planning **system architecture** for performance and reliability
- ⚡ Improving speed with **caching, indexing, and query optimization**
